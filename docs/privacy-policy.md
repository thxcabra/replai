# Privacy Policy — Replai

**Last updated:** 2026-06-14

Replai is a Chrome browser extension built by Moic Digital for internal use by analysts at moicdigital.com. This policy explains what data the extension collects, where it goes, and how it is protected.

## 1. Who this applies to

Only users authenticated with a Google Workspace account on the **@moicdigital** domain can use Replai. Login attempts from other domains are rejected by our backend (Supabase) before any account is created.

## 2. What data we collect

When you use Replai, the following data is collected and stored in our Supabase database (RLS-enforced row-level isolation):

### Account data (from Google OAuth)
- Email address
- Display name (`raw_user_meta_data.full_name` from Google)
- Supabase-issued user ID

### Configuration
- Workspaces you create (name, X List ID, LLM provider/model choice, time-window filters)
- Voice/personality text you paste or upload (.md/.pdf/.txt) per workspace
- API keys you provide for Gemini and/or Anthropic (stored encrypted at-rest with AES-256 via Supabase EBS)

### Activity data
- Tweets you triage and respond to: tweet ID, URL, author handle, text, language, social-graph metrics (ISV, POI status, inferred layer), engagement context (`tweet_age_minutes`, hashtags, mentions)
- Reply suggestions generated by the LLM (all 3 candidates per tweet)
- Which reply you chose, whether you edited it, whether you confirmed posting it
- Session metadata: timing, LLM tokens used, estimated cost
- Operational events (button clicks, errors) — sanitized to strip any API keys before storage

### What we do **not** collect
- Browsing history outside the extension
- Tweets you don't triage through Replai
- Content of other browser tabs
- Your interactions with the X website itself (post-confirmation is a self-reported click in the extension dialog)

## 3. Where the data goes

- **Supabase** (hosted Postgres) — primary store, RLS enforces that each user can only read/write their own rows
- **Anthropic** and/or **Google AI (Gemini)** — receives the tweet text + your workspace voice as the LLM prompt; output is the reply suggestions
- **twitterapi.io** — third-party service used to fetch tweets from X Lists (no user identity sent, only API key)
- **Google OAuth** — only the OAuth token exchange, no other data

Data is **not** sold, shared with advertisers, or sent to third parties beyond what is required for the extension to function.

## 4. Admin access (limited use)

Users with `admin` role in the `user_roles` table can:
- View aggregated activity metrics (counts, conversion rates) of all team members
- Export raw reply logs (CSV/JSON) of any team member for analysis
- Promote or revoke admin role for other team members

Admin role is granted manually by inserting into the `user_roles` table in the Supabase SQL Editor. This is a privileged operation restricted to the workspace owner.

## 5. Data retention

- Workspaces, voice, and reply logs are retained indefinitely so that long-term analytics remain available
- Users can delete their own data by deleting the workspace (cascades to replied_tweets, voice_versions, session_logs) or by requesting account deletion (contact: you@example.com)

## 6. Security

- All data in transit is encrypted via HTTPS
- All data at rest in Supabase is encrypted (AES-256 via AWS EBS)
- Row-Level Security policies isolate user data at the database level
- API keys are stored encrypted; never sent in URLs or logged in plaintext events

## 7. Limited Use compliance (Google API Services)

Replai's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. The Google OAuth identity is used **only** to authenticate you to your Supabase profile; it is never sold, transferred to other apps, or used for advertising.

## 8. Children's privacy

The extension is for use by employees of Moic Digital and is not directed at children under 13.

## 9. Changes to this policy

Material changes will be notified to all users via the side panel UI on next open. The "Last updated" date at the top reflects the current version.

## 10. Contact

For privacy questions, account deletion, or admin role requests: **you@example.com**
